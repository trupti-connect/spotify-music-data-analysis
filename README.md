# 🎵Spotify Hit Song Analyzer: Predicting Hit Songs and Discovering Music Trends

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on a Spotify music dataset containing **114,000+ songs**. The objective is to analyze music characteristics, discover trends across genres, identify factors affecting song popularity, and create insightful visualizations using Python.

The project demonstrates essential **data analytics** skills including data cleaning, feature exploration, statistical analysis, and visualization.

---

## 📊 Dataset Information

* **Dataset:** Spotify Tracks Dataset
* **Total Records:** 114,000
* **Total Columns:** 21

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/Spotify-Music-Data-Analysis.git
```

Move into the project folder

```bash
cd Spotify-Music-Data-Analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Jupyter Notebook

```bash
jupyter notebook
```
